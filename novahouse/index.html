novahouse

a telegram bot that turns your server into a smart home hub — control your pc, capture webcam, manage audio, wake on lan, and run ai queries. all from your phone.

view on github
features
remote control
mouse, keyboard, open urls on your pc
wake on lan
boot your pc remotely via magic packet
webcam / screen
capture and send snapshots to telegram
audio control
volume up/down/mute via pactl
ai module
gemini, openai, deepseek, ollama
shell access
run commands on server or pc
install
bash 
python3 setup.py

clone the repo first — the wizard handles everything else.

config.json keys
BOT_TOKEN your telegram bot token from @botfather
ALLOWED_USERS list of telegram user IDs allowed to use the bot
PC_IP / PC_USER ip address and ssh username of your pc
MAC_ADDRESS mac address for wake-on-lan
AI_PROVIDER gemini / openai / deepseek / qwen / local / none
