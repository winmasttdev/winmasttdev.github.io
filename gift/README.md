# Сайт-подарок "Ретро-камера воспоминаний" 📸

Этот сайт сделан для твоей подруги детства. Он стилизован под ретро-цифровой фотоаппарат Y2K (Cyber-shot) с интерактивным управлением, оранжевой датой, фильтрами, зумом, звуком затвора и встроенным кассетным плеером.

## Как запустить сайт локально?

Мы уже запустили для тебя локальный веб-сервер на порту **8080**.
Сайт можно открыть в браузере по адресу:
👉 **[http://localhost:8080](http://localhost:8080)**

Если ты хочешь запустить сервер заново в будущем, выполни команду в терминале:
```bash
python3 -m http.server 8080
```
*(Или запусти сервер в любой среде разработки, например, Live Server в VS Code).*

## 🎵 Как добавить любимую песню "OG Buda - откровения"?

В коде настроен автоматический подхват аудиофайла. Тебе нужно перенести файл песни в следующую папку:
📂 `/home/winmastt/.gemini/antigravity/scratch/friendship-site/assets/music/`

И переименовать файл песни в **`song.mp3`** (или `song.wav`). Полный путь к файлу должен быть:
📍 `/home/winmastt/.gemini/antigravity/scratch/friendship-site/assets/music/song.mp3`

> [!TIP]
> **Встроенный синтезатор (Fallback):**
> Если ты еще не закинул аудиофайл, не волнуйся! В коде реализован встроенный синтезатор мелодии на Web Audio API. При запуске камеры начнет играть приятная теплая ретро-lofi мелодия, а индикаторы плеера будут двигаться. Как только ты положишь файл `song.mp3` на место, сайт автоматически переключится на воспроизведение песни!

## 🕹️ Управление на сайте (как на настоящей камере!)

* **Кнопка "ПОДАРУНОК ДЛЯ ТЕБЕ" (Объектив):** Включает камеру, запускает музыку и воспроизводит звук включения объектива.
* **Стрелки влево `<` и вправо `>` на D-pad:** Переключение фотографий (каждая имеет свой оригинальный оранжевый штамп даты и времени!).
* **Кнопка `DISP` (в центре D-pad):** Меняет цветовые фильтры на дисплее камеры (Обычный ➡️ Черно-белый ➡️ Сепия ➡️ Киберпанк-фиолетовый).
* **Кнопка `W` / `T` (Zoom):** Приближает (`T`) и отдаляет (`W`) текущее фото на экране.
* **Большая серебряная кнопка `Shutter` сверху:** Делает снимок — экран вспыхивает белым, звучит механический затвор и появляется уведомление "СНИМОК СОХРАНЕН В ГАЛЕРЕЮ".
* **Кнопка `MUSIC` (на корпусе):** Включает/выключает музыку.
* **Стрелка вниз `v` на D-pad:** Открывает выдвижной кассетный плеер, где крутятся бобины кассеты, показывается время трека и можно регулировать громкость.
* **Кнопка `MENU` (на корпусе):** Включает/выключает ЖК-сетку (LCD scanlines) на экране для еще более ретро-вида.
* **Стрелка вверх `^` на D-pad:** Переключает режим вспышки (Вспышка принудительно ➡️ Авто вспышка ➡️ Вспышка выключена).
